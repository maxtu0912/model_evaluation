# DeepSeek Flash 与 V4 Pro：C-Eval 对比结论

本结论依据仓库中的 Flash 历史报告和 2026-10-12 完成的 V4 Pro 评测。两次均为 C-Eval test 全量 12,342 题、52 学科，数据指纹和提示版本相同，使用零样本、关闭思考模式、温度 0、最大输出 32 token。

## 总体表现

| 指标 | Flash（历史结果） | V4 Pro（本次） |
|---|---:|---:|
| 正确题数 | 10,861 | 11,126 |
| 逐题正确率 | 88.00% | 90.15% |
| 学科等权平均 | 88.22% | 90.10% |
| 最终请求失败 | 0 | 0 |
| 无法提取单一选项 | 0 | 5 |

Pro 多答对 265 题，逐题正确率提高 2.15 个百分点，错误题数减少约 17.9%。52 个学科中，Pro 在 35 个领先、6 个持平、11 个落后，整体优势有一定广度。

## Pro 的优势

四大类别均领先，职业资格等所在的 Other 类提升最大。

| 类别 | Flash | Pro | Pro − Flash |
|---|---:|---:|---:|
| Other（含职业资格等） | 87.60% | 91.13% | +3.52 个百分点 |
| STEM | 86.05% | 87.84% | +1.79 个百分点 |
| 社会科学 | 90.95% | 92.62% | +1.67 个百分点 |
| 人文学科 | 88.71% | 89.93% | +1.23 个百分点 |

| 提升突出的学科 | Flash | Pro | Pro − Flash |
|---|---:|---:|---:|
| 注册消防工程师 | 80.85% | 92.20% | +11.35 个百分点 |
| 高中数学 | 68.07% | 76.51% | +8.43 个百分点 |
| 初中数学 | 87.01% | 92.66% | +5.65 个百分点 |
| 税务师 | 86.91% | 92.33% | +5.42 个百分点 |
| 公务员 | 89.28% | 94.64% | +5.36 个百分点 |
| 工商管理 | 83.39% | 88.70% | +5.32 个百分点 |

本次结果更支持 Pro 用于这类中文知识选择题，尤其是职业资格和部分数学题。但不能把这些选择题结果直接解释为真实专业工作或复杂推理任务的可靠性。

## Flash 的局部优势

| 学科 | Flash | Pro | Flash 多答对 |
|---|---:|---:|---:|
| 临床医学 | 94.00% | 91.00% | 6 题 |
| 导游资格 | 95.11% | 93.23% | 5 题 |
| 注册计量师 | 89.95% | 88.13% | 4 题 |
| 计算机组成 | 90.16% | 88.60% | 3 题 |

Flash 领先的 11 个学科中，7 个仅相差 1–2 题，不足以认定它在这些领域普遍更强。基础学科中两者已接近满分的题目，Pro 的增益也较小。

Flash 的全部回答可提取为单一选项；Pro 有 5 个回答输出多个选项，占 0.04%，按原规则计错。Flash 本次对单字母输出格式的遵循稍好。

## 共同短板和比较范围

- 数学和部分工程学科仍较弱。Pro 的高等数学为 72.25%、高中数学为 76.51%；概率统计和离散数学分别为 75.30%、75.82%，还略低于 Flash。
- 总分接近 90% 不表示每个学科都可靠，应用时应查看具体学科结果。
- Pro 的耗时包含限流等待与重试；本次未统一测量成本，不能判断两者的速度和成本优劣。
- Flash 为历史结果，未记录可核实的不可变模型快照。本结论比较两次实际运行，不归因于单一架构差异。
- 题目公开，可能存在训练数据污染；仅评测非思考模式的中文选择题，不覆盖实际编程、Agent、开放式写作或思考模式。
- 只有 Pro 的本地逐题记录，Flash 只有汇总报告，因此不能判断哪些具体题目被修正，也没有进行配对显著性检验。
