## 固定协议

- 模型：`doubao-seedream-5-0-flash-260915`。
- 接口：`https://ark.cn-beijing.volces.com/api/v3/images/generations`。
- 题集：`cases/image-smoke-v1.jsonl`，10 道自建题，不是官方 GenEval 子集。
- 覆盖：对象、数量、颜色、空间位置、属性绑定、中文文字、海报布局、多约束、木刻风格。
- 每题单次生成，1024×1024，PNG，watermark=false，Base64 返回。
- 没有传入种子或自动提示词优化参数；服务端默认行为不能视为关闭。
- 所有检查项在运行前写入题集。生成成功不代表质量检查通过。
- 本轮采用助手视觉复核；正式评测需校准评分器并增加人工盲评。本轮不足以形成排行榜结论。
- 最多 10 次新生成请求。遇到失败立即停止，不自动重试超时，不切换模型。
- POST 前保存请求意图；恢复时跳过已尝试的请求，避免中断后重复计费。
- 日志、复核和图片保存在 `artifacts/seedream-flash-smoke/`，按用户要求纳入版本控制。
- API Key 在被 Git 忽略的 `.env` 中保存，不写入产物与汇总报告。

## 开通模型后续跑

```sh
python3 image_eval.py --retry-rejected
```

该参数仅允许重新提交此前 HTTP 404 拒绝的请求。质量失败不重生成；
状态未知的请求需要人工检查，不能直接重试。

接口用量不等于实际费用；成本需按账户账单核实，不假设失败请求免计费。

官方接口文档：https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh
